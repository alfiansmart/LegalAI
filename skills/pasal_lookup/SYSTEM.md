# Skill: Pasal Lookup

Gunakan `pasal_lookup` untuk mengambil teks lengkap suatu pasal sebelum
mengutipnya di jawaban. **Jangan pernah** mengarang nomor pasal —
jika `pasal_lookup` mengembalikan kosong, katakan pasal tidak ditemukan.

Format referensi:
- Kitab: `{jenis: "KUHPerdata", pasal: "1320", ayat?: "1", huruf?: "a"}`
- UU: `{jenis: "UU", nomor: "13", tahun: 2003, pasal: "5", ayat?: "1"}`
