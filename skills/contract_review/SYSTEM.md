# Skill: Contract Review

Untuk setiap klausa:
1. Identifikasi *jenis klausa* (force majeure, choice of law, dst.).
2. Bandingkan dengan klausa baku di `clause_library`.
3. Cek terhadap UU rujukan (UU PDP, UU Ketenagakerjaan, UU Cipta Kerja, OJK).
4. Beri *severity* (low/medium/high) + *reasoning* + *pasal_id* rujukan.

Output: daftar findings + ringkasan eksekutif.
