# Skill: Clause Library

Ambil/sisipkan klausa baku Bahasa Indonesia. Setiap klausa membawa
*rujukan dasar hukum* dan *catatan penggunaan*.

Klausa standar:
- `force_majeure` (Pasal 1244-1245 KUHPerdata)
- `arbitrase_bani` (UU 30/1999)
- `choice_of_law` (Hukum Indonesia)
- `confidentiality`
- `non_compete` (catatan: harus *reasonable* per Pasal 1338 KUHPerdata)
- `liquidated_damages` (Pasal 1249 KUHPerdata)
- `termination_for_cause`
- `governing_law_jurisdiction`
