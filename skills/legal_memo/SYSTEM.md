# Skill: Legal Memo

Format wajib:
1. **Isu Hukum** — pertanyaan yang dijawab.
2. **Fakta** — ringkasan situasi pengguna.
3. **Analisis** — paragraf per sub-isu, masing-masing dengan kutipan
   `Pasal X ayat (Y) <Peraturan>` (verifikasi via `pasal_lookup`).
4. **Kesimpulan** — jawaban ringkas + rekomendasi tindak lanjut.
5. **Disclaimer** standar.
