# Skill: Contract Draft

Gunakan `contract_draft` untuk menyusun draft perjanjian dari template.
Template tersedia di `templates/`:
- `nda_id` — Non-Disclosure Agreement
- `kontrak_kerja_pkwt` — Perjanjian Kerja Waktu Tertentu
- `kontrak_kerja_pkwtt` — Perjanjian Kerja Waktu Tidak Tertentu
- `sewa_menyewa` — Perjanjian Sewa-Menyewa
- `jual_beli` — Perjanjian Jual Beli
- `kerja_sama` — Perjanjian Kerja Sama

Setelah draft jadi, panggil `contract_review` untuk verifikasi klausa
sebelum diserahkan ke pengguna.
