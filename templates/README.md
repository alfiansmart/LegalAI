# Document Templates

Templates for `contract_draft`. Phase-1 ships markdown templates with
Jinja2 placeholders; Phase-2 adds `.docx` rendering with proper
Indonesian legal formatting (kop, materai placeholder, blok tanda
tangan, lampiran).

Available slugs:

| slug | jenis |
|---|---|
| `nda_id` | Non-Disclosure Agreement |
| `kontrak_kerja_pkwt` | PKWT |
| `kontrak_kerja_pkwtt` | PKWTT |
| `sewa_menyewa` | Sewa-menyewa |
| `jual_beli` | Jual beli |
| `kerja_sama` | Perjanjian kerja sama |
| `somasi` | Somasi |
| `surat_kuasa` | Surat kuasa |
